Use positive and negative points on the frame that best represents the shot. The prompt stays in the project, so you can return to it.

04 / Clean Up

Subtitles and logos are different jobs.

Use the target that matches the overlay. Subtitle detection stays separate from watermark detection, so one never widens the other.

Auto or guided

Remove subtitles

Detects caption-shaped regions, then cleans them from the preview and exports. Draw a box when a caption is unusual or always on.

  • Flickering captions use a clean temporal plate.
  • Always-on captions use per-frame glyph repair.
Faint marks welcome

Remove logos & watermarks

Corner marks, wordmarks, and low-opacity white overlays are detected with local contrast and temporal stability, then repaired with a feathered inpaint.

  • Use Mask to End for smooth long-clip playback.
  • Use Regenerate when a repair needs a different grain.
i

Best result: draw a slightly larger box than the visible mark. The padding gives the repair room to remove anti-aliased edges and faint traces.

08 / Common questions

When the matte misbehaves.

Start with the smallest change that addresses the problem.

Why is my hair disappearing?

Lower Edge smoothness, raise Detail preservation, and turn off temporal smoothing for a close-up. The QC Coach gives the same answer when you type “hair is too smooth”.

Why do my exported edges look jagged?

Raise Edge softness in the Shot Profile dialog. It anti-aliases the exported matte and removes the background colour from edge pixels, instead of writing hard 0/255 alpha. 0 restores a hard matte if a downstream tool needs one.

Why does the edge flicker between frames?

Enable temporal smoothing and use a two-frame window. If the subject is moving quickly, add a correction keyframe instead of over-smoothing the whole shot.

A faint white watermark is still visible. What now?

Use Remove Logo, choose the guided region, and draw a slightly larger box. Then press Mask to End so the same repair is applied consistently through the clip.

Does Better Brush upload my footage?

No. The desktop app is designed to keep processing local. Model files and project files stay under your control.

What if I need to try a risky change?

Create a checkpoint first. Version History stores recoverable project snapshots you can compare and restore.
